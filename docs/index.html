Guide

Usage: https://recauth.github.io/proc?q=... or ?q=@slug for canned text
 
List of usable q prefix (with space after):
  • //some.domain
  • h or help -> Help
  • g Text -> Google (for both ask/search)
  • ----------------------------------------
  • b Text -> Bing
  • c Text -> Claude
  • d Text -> DuckDuckGo
  • e Text -> Ecosia
  • h Text -> HuggingChat
  • m Text -> Meta AI
  • p Text -> Presearch
  • y Text -> Yahoo
  • br Text -> Brave
  • ch Text -> ChatGPT
  • cp Text -> Copilot
  • da Text -> Duck AI
  • ga Text -> Google AI Mode
  • ge Text -> Gemini
  • gr Text -> Grok
  • pp Text -> Perplexity
  • ----------------------------------------
  • gdt Google Drive Thumbnail URL
